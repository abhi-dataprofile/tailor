Local model & providers

      
    

  

  

    
Local model

    
Pick which engine does the AI work. Only the one you choose connects — so the local model won't load into memory unless you select it.

    
    

    

      
Optional: Claude API (best quality)

      
Paste an Anthropic API key to use Claude for the writing instead of the local model. If the key is set it's used first; if it's missing, invalid, expired, or out of credit, the app automatically falls back to Ollama, then to heuristics. Your key is stored only in this browser and sent only to Anthropic — anyone with access to this device could read it, so use it only on a machine you trust.

      
      
      
Cheaper: claude-haiku-4-5-20251001. Highest quality: claude-opus-4-8.

    

    

      
Optional: Google Gemini API

      
Paste a Google AI Studio key to use Gemini. Used after Claude and before Ollama, with the same automatic fallback. Your key is stored only in this browser and sent only to Google — use it only on a machine you trust. Get a key at aistudio.google.com/apikey.

      
      
      
Fast/cheap: gemini-2.5-flash. Higher quality: gemini-2.5-pro.

    

    

      
Optional: OpenAI API

      
Paste an OpenAI key to use GPT. Stored only in this browser, sent only to OpenAI. Get a key at platform.openai.com/api-keys.

      
      
      
Cheaper: gpt-5-mini or gpt-4o-mini. Highest quality: gpt-5.5.

    

    

      
Optional: Custom / cheap API (OpenAI-compatible)

      
Works with any OpenAI-compatible vendor — much cheaper than Claude. Presets: OpenRouter https://openrouter.ai/api/v1 with model deepseek/deepseek-v4-flash (~$0.14/M in) or z-ai/glm-5.2; DeepSeek direct https://api.deepseek.com; Z.ai GLM https://api.z.ai/api/paas/v4. If a vendor blocks browser calls (CORS), use OpenRouter — it works from browsers. Key stored only in this browser.
